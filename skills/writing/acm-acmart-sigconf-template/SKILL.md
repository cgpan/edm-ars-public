# ACM acmart sigconf Template

The Writer fills `%%PLACEHOLDER:SLOT_NAME%%` markers in the bundled
template. The structural LaTeX (document class, rights management, author
block, CCS concepts, bibliography commands, `\begin{abstract}` before
`\maketitle`, `\begin{acks}`, etc.) is fixed and must NOT be modified.

The template file is bundled alongside this SKILL.md as
`paper_template_v2.tex`. Load it via `skill.resource_paths[0]`.

## Output rules

1. Start with the EXACT template text provided.
2. Replace every `%%PLACEHOLDER:SLOT_NAME%%` marker with the appropriate
   content.
3. **Do NOT modify any LaTeX structural commands**: `\documentclass`,
   `\author`, `\affiliation`, `\maketitle`, `\bibliographystyle`,
   `\begin{document}`, `\end{document}`, `\begin{acks}`, `\setcopyright`,
   `\settopmatter`, `\acmConference`, `\makeatletter`, `\makeatother`,
   `\renewcommand\@copyrightpermission`, `\begin{CCSXML}`, `\ccsdesc`,
   etc.
4. Do NOT add any `\usepackage` commands. The template already loads
   `booktabs`, `graphicx`, and `threeparttable`.
5. **Do NOT change the author information** — it is fixed (EDM-ARS).
6. Output the COMPLETE filled-in template in a ```latex block.
7. If the `%%PLACEHOLDER:APPENDIX%%` slot is not needed, remove that
   line entirely.

## v2 (outline-first) template

The bundled template is `paper_template_v2.tex`, which has a single
`%%PLACEHOLDER:PAPER_BODY%%` slot for the entire body. Section structure
is generated by the OutlineAgent (see the `paper-narrative-outline`
skill) and produced by the Writer as one cohesive body.

If a v1 template (per-section placeholders) is referenced anywhere, it
is deprecated; v2 is canonical.

## Placeholders in v2

| Placeholder | Content |
|---|---|
| `%%PLACEHOLDER:TITLE%%` | Paper title (concise, descriptive). |
| `%%PLACEHOLDER:ABSTRACT%%` | Abstract prose, 200–300 words. Plain text only. |
| `%%PLACEHOLDER:KEYWORDS%%` | Comma-separated keywords. |
| `%%PLACEHOLDER:PAPER_BODY%%` | All sections (Introduction through Discussion) generated from the outline. |
| `%%PLACEHOLDER:APPENDIX%%` | Critic appendix when verdict != PASS; otherwise remove the line. |

## Auto-generation disclosure

The Methods section MUST include this exact sentence (in METHODS_DATA or
as a standalone paragraph at the end of that subsection):

> This study was conducted using EDM-ARS, an automated educational data
> mining research system. All data preparation, model training,
> evaluation, and manuscript generation were performed programmatically.

## Title format

Write a concise, descriptive title that accurately reflects the research
question, methods, and context. No fixed structure. Useful patterns:

- "[Method] for Predicting [Outcome] Using [Key Predictors] in [Context]"
- "Predicting [Outcome] in [Population]: A [Method] Approach"
- "[Outcome] Prediction via [Method]: Evidence from [Dataset/Context]"
- "Early Identification of [Outcome]: Insights from [Key Predictors] and [Method]"
- "Who Is at Risk? Predicting [Outcome] with [Method] in [Context]"

Avoid titles that are generic or interchangeable with other EDM papers.
