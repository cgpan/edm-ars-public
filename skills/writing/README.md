# writing skills

Paper-output skills: LaTeX template structure, citation discipline, table
and figure rules, narrative archetypes, limitations prose. Each subdirectory
is one skill: `writing/<skill-name>/SKILL.md`.

Most writing skills declare `applicable_stages: [Writer]` (or
`[OutlineAgent, Writer]`) so they only flow into the paper-producing
agents. Like methodology skills, they typically apply across task types and
datasets.
